## 概要
このリポジトリには、国際学術誌Neurochemistry Internationalに掲載された論文のデータ分析コードと結果が格納されています。グラフの見た目は掲載されたものと異なりますが、データ分析結果は一致しています。  
先行研究[（下田ら、2024）](https://github.com/RyoShimoda/Analyse_MSSE)で明らかになった、４週間の低強度運動による恐怖記憶消去促進の脳神経メカニズムとして、背側海馬アンモン角（CA3）の活性低下が関与していることを示唆しています。こちらも先行研究同様、心的外傷後ストレス障害（PTSD）への運動療法の可能性や、そのメカニズム解明に迫った研究です。  
実験データは等分散性の検定（Levene検定）や球面性検定（Mendoza）を行った後、繰り返しのある二元配置分散分析や繰り返しのない一元配置分散分析を行い、Shafferの方法を用いて事後検定を行いました。神経活性の相関分析には、Pearsonの積率相関分析を行いました。

- 研究概要  
まず、ラットに軽微な電気ショックによる恐怖条件付けを行い、恐怖記憶（トラウマ記憶）を学習させます。その後、安静群、低強度運動群に分け、４週間の運動、あるいは安静を実施したのち、恐怖記憶の消去学習（恐怖症状を緩和していく実験、PTSDの治療に用いられる暴露療法に類似）を実施、その後脳のサンプリングを行い、前頭前皮質や海馬、扁桃体の神経活性を、神経活性のマーカーであるc-Fosタンパク質を用いて評価しました。行動実験の結果、安静群に対し、低強度運動群で、消去学習が促進され、恐怖症状が緩和しました。その際の神経活性を評価すると、安静群に対し、低強度運動群では海馬腹側歯状回（vDG）および背側海馬アンモン角（dCA3）の神経活性が低下していました。神経活性と恐怖の指標である立ちすくみ時間の相関を分析すると、dCA3と立ちすくみ時間に有意な正の相関関係がありました。このことから、４週間の低強度運動による恐怖記憶の消去学習促進には、dCA3の神経活性低下が関与していることが示唆されました。


## Regular light-intensity exercise accelerates contextual fear extinction with reduced dorsal CA3 activation in male rats

This repository contains the R code and related materials for the data analysis presented in the following paper:

> Taichi Hiraga; Ryo Shimoda; Toshiaki Hata; Ferenc Torma; Masahiro Okamoto; Hideaki Soya (2026).
> Regular light-intensity exercise accelerates contextual fear extinction with reduced dorsal CA3 activation in male rats.
> Neurochemistry International, Volume 198, September 2026, 106191, DOI: 10.1016/j.neuint.2026.106191

## Reproducibility & Output Notes
### Code Origin & Figures:
The R scripts in this repository are the original code the author used during analysis. While the underlying data and statistical results match the published paper, the exact plotting scripts may differ from those used by the co-author who generated the final figures for the manuscript.
### Automatic Directory & Extra Outputs:
Upon running the scripts, the required output directories (e.g., /Individual_data) will be automatically created within your working directory.
### Exploratory Files:
Please note that the generated folders will contain more files and plots than those explicitly presented in the paper. These include intermediate data, preliminary visualizations, and exploratory analyses performed during the research process.
